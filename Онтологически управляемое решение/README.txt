Для запуска кода в файле "Онтологически управляемое решение v5.py" в среде VS code, необходимо:
⚙️ Требования

Перед запуском убедитесь, что установлено:

Python 3.10 или выше
pip (идёт вместе с Python)
VS Code (рекомендуется)

Проверка Python:

python --version
📦 Установка зависимостей

Откройте терминал в папке проекта (VS Code → Terminal) и выполните:

pip install pandas openpyxl

tkinter устанавливать не нужно — он уже встроен в Python.

📁 Подготовка файлов

В проект необходимо добавить:

.ont файл (онтология)
.xlsx файл (данные продуктов и нормы)

⚠️ Пути к этим файлам указываются вручную в коде.

✏️ Настройка путей

Откройте файл с кодом и найдите строки:

ONT_PATH = "..."
EXCEL_PATH = "..."
OUTPUT_DIR = "..."

Замените на реальные пути к вашим файлам, например:

ONT_PATH = r"C:\path\to\document.ont"
EXCEL_PATH = r"C:\path\to\document.xlsx"
OUTPUT_DIR = r"C:\path\to\output"

В версии выше 5, вводить путь не нужно

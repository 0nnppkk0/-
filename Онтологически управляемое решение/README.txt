Для запуска кода в файле "Онтологически управляемое решение v5.py" в среде VS code, необходимо:
⚙️ Требования

Перед запуском убедитесь, что установлено:

Python 3.10 или выше
pip (идёт вместе с Python)
VS Code (рекомендуется)

Проверка Python:

python --version
📦 Установка зависимостей

Откройте терминал в папке проекта (VS Code → Terminal) и выполните:

pip install pandas openpyxl

tkinter устанавливать не нужно — он уже встроен в Python.

📁 Структура проекта

В папке проекта должны находиться:

Ontology-controlled solution Sv16Garbage collection.py
Онтология.ont
Нутриенты.xlsx
Запускt.bat

▶️ Запуск программы

Для запуска программы:

Дважды нажмите на файл:
Запускt.bat

📊 Что делает программа

Программа:

загружает онтологию из .ont
загружает нутриенты и нормы из .xlsx
позволяет выбрать употребляемые продукты
проводит опрос по частоте и порциям
рассчитывает нутриенты
сравнивает результаты с нормами
формирует Excel-отчёт

📄 Excel-отчёт

После завершения опроса автоматически создаётся файл:

опрос_и_анализ.xlsx
